# 开篇篇章：朱元璋的早年经历｜旁白初稿 v0.2，未锁定

这是本次限定范围的完整候选稿，涵盖出生、家变、入寺、游方与返寺，1352年仅作下集引子；不宣称对应出版版第一章完整边界。N01–N08 为约 75–90 秒样片候选，具体以真实语音测量；停顿用标点表达，不口播斜杠。

**N01 / S01** 后来，他建立了一个王朝。可少年时，他首先得想办法活下去。

**N02 / S02** 一三二八年，朱元璋出生在濠州钟离，也就是今天安徽凤阳一带。家里穷，日子要靠土地撑着。

**N03 / S03** 一三四四年，灾荒和疾病袭来。他的父母和多位亲人相继去世。一个家，就这样散了。

**N04 / S04** 为了谋生，他走进寺院。可在灾年，连寺院也养不起这么多人。

**N05 / S05** 没过多久，他又上了路，靠乞食度日。从村庄到城镇，先解决眼前这一餐，才有力气想明天。

**N06 / S06** 大约三年后，他回到寺院。外面的天下，却并没有安静下来。

**N07 / S07** 一三五二年，濠州起事。朱元璋加入了郭子兴的队伍。曾经为下一顿饭奔走的年轻人，走进了另一场风暴。

**N08 / S08** 接下来，他会怎样在乱世中站稳脚跟？故事，才刚刚开始。

读音提示：朱元璋 Zhū Yuánzhāng；濠州 Háozhōu；钟离 Zhōnglí；凤阳 Fèngyáng；郭子兴 Guō Zǐxīng。年份逐字读“一三二八年、一三四四年、一三五二年”；实际听审纠正多音字。N05 的“先解决……”是叙述者对生存处境的概括，不是人物引语或心理证词。克制幽默，不在丧亲情节插科打诨。
