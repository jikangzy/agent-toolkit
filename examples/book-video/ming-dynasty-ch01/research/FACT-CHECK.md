# 史实核查清单｜开篇篇章

检索日期：2026-10-30。独立资料并非彼此完全独立的原始证据：两者都可能依赖传统史料；故宫材料与学术著作是交叉参照，不代表所有细节无争议。来源编号见文末。

| 内容 | 判断与叙事处理 | 来源 |
|---|---|---|
| 1328年出生，祖籍活动地濠州钟离、今安徽凤阳一带 | 故宫给出出生年和地点；用现代地名作方位提示，不把现代县界当元代行政边界 | A、B |
| 农家贫困；父朱世珍、母陈氏 | 故宫列出父母；港大出版社称家庭贫困。父亲别名及称谓暂不进入旁白 | A、C |
| 1344年灾荒与疾病，父母和多位亲人去世 | 故宫确认父母兄相继亡故，C将其置于灾荒疾病背景；不指定每人死因、死亡日期及顺序 | B、C |
| 寺院谋生后外出乞食，约三年后返回 | A和C均叙述入寺及外出求生；C称约三年。寺院早期名称写法有差异，脚本用“寺院”，必要时标注“后称皇觉寺” | A、C、D |
| 游方途经具体各城、寺内具体劳役与受辱对话 | 资料及版本尚需原始史料逐项复核，画面不标精确路线，不使用对白 | 用户PDF [4]–[6] 为文学叙述，非独立证据 |
| 埋葬时地主拒绝、邻人具体帮助 | 合集 [3] 描写，未完成独立原始史料核查；暂不拍成确定事件 | 用户PDF [3] |
| 少年的梦想、怨恨、预见未来、佛教/明教信仰归属 | 主观心理或诠释；不当作事实口播 | 用户PDF [2]–[6] |
| 1352年投郭子兴 | C载其于该年加入；为后续预告，不作为童年已知章节边界 | C |
| 明朝建立 | 1368年；仅开场结果性铺垫，不制造“当时已是明朝”的错觉 | A |

A [故宫博物院：太祖开国](https://www.dpm.org.cn/court/event/166593.html)；B [故宫博物院：朱元璋](https://www.dpm.org.cn/lemmas/242999.html)；C [Ellen Soulliere, *The Empress and the Dragon Throne*, HKU Press, pp. 27–28](https://hkupress.hku.hk/image/catalog/pdf-preview/9789888900787_preview2.pdf)；D [中国文化研究院](https://www.chiculture.org.hk/en/china-five-thousand-years/4066)。
